# Learning Go
Learning Go by building an HTTP server

## Getting Started
`Thing` is the basic service with the most basic CRUD ops to use as an example for building out other services

### Adding Services
Using `Thing` as a template, you can build other service folders and copy the basic CRUD ops
You'll also need to add:
- a store type to the Application struct
- routes in `routes.go`
- collection in `main.go`
